# 安全设计

## 权限边界

- MCP 进程以 DSM 为套件建立的专用账户运行，不给 shell 工具 root 权限。
- 安装后默认只授权专用工作目录。共享目录必须显式加入授权列表，并确认 DSM 文件权限使套件账户可访问。
- Desktop Commander 的 `allowedDirectories` 必须至少包含一个有效目录；空数组在上游表示不限制目录。
- 高风险 Shell 命令由上游命令检查与 DSM 专用账户权限共同约束。不能把命令黑名单当作完整沙箱。

## 网络与授权

- NAS 不监听公网 MCP 管理端口；远程工具调用由官方设备代理主动连接 Desktop Commander Remote。
- 设备码、验证链接和到期时间只显示上游真实返回值；本地 UI 不生成模拟授权状态。
- 授权凭据位于 DSM 持久变量目录，权限限制为套件用户可读；不得写入仓库或普通日志。
- 上游遥测默认关闭。设备代理的数据流经过 Desktop Commander 官方 Remote MCP 服务，安装说明必须披露这一点。
- 管理页面应通过 DSM 套件入口打开，并避免新建额外的公网端口或修改 NAS 网络设置。

## 日志

- 服务日志限制大小并轮转；界面仅显示经过脱敏的内容。
- 命令行参数、授权码、访问令牌、刷新令牌及文件内容不得出现在普通服务日志中。
- Desktop Commander 本地工具历史可能包含调用参数。正式版必须核查并实现符合上项的脱敏策略后，才可启用对应历史工具。
