# DSM 覆盖安装与升级

本项目遵循 [DSM-SPK 覆盖安装与升级指南](../docs/DSM-SPK-覆盖安装与升级指南.md) 中的实测规则：

- 套件身份 `package` 在所有版本保持不变。
- SPK 内部版本递增，例如 `1.0.0-0001`。
- 用户配置、Remote 设备授权和日志放在 `SYNOPKG_PKGVAR`，不放在可替换的程序目录。
- 升级执行旧版卸载脚本时不得清除持久变量目录。
- `preupgrade` 只检查，不迁移或删除；`postupgrade` 仅补齐目录和权限。
- 正式验收必须在目标 NAS 保留已安装版，通过 DSM 套件中心手动上传新版确认就地升级。
